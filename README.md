# Tex Murphy: Overseer — Modern Windows Fix

A fix for the compatibility issues that stop *Tex Murphy: Overseer* (GOG and Steam versions) from running properly on Windows 10 and 11.

## How to use it

1. **Steam version:** exit Steam completely first (Steam menu → *Exit*).
2. Download this fix (green **Code → Download ZIP** button) and unzip it anywhere.
3. Double-click **`Install.cmd`** and click *Yes* when Windows asks for permission.
4. Play: start the game the way you normally would — the GOG shortcut or GOG Galaxy, or **Play** in Steam.
   When the *System Checker* window appears, click **Continue**.

If the game stops working after GOG Galaxy or Steam repairs or verifies its files, just run `Install.cmd` again.

## Removing it

Double-click **`Uninstall.cmd`** (exit Steam first). Everything is put back the way it was.

## Something not working?

Run **`Diagnose.cmd`**, then [open an issue](../../issues) and attach the file it saves on your Desktop.
